# Diode Network 商業計畫書

## 一、產品定位

### 產品名稱
**Diode Cloud** — 端對端加密隧道即服務 (Encrypted Tunnel as a Service)

### 一句話描述
為 App 開發者提供全球多區域的加密代理節點，透過 API 整合，按連線人數和流量計費。

### 核心價值
| 特點 | 說明 |
|------|------|
| 端對端加密 | 基於 secp256k1 的 E2E 加密，後台無法解密流量（vs Cloudflare 會終止 TLS） |
| API 驅動 | App 用 key/secret 直接呼叫 API 取得節點，無需手動配置 |
| 多區域部署 | 全球節點自動分配，App 可選擇區域 |
| 即時管理後台 | Web UI 監控節點、連線、用量，一目了然 |
| 彈性計費 | 按同時連線數 + 網路流量計費，用多少付多少 |

### 目標客群
1. **IoT 設備開發商** — 需要安全遠端存取設備（NAT 穿透）
2. **企業遠端辦公** — 加密連線至內部服務
3. **App 開發者** — 需要代理/隧道基礎設施但不想自建
4. **遊戲/直播** — 需要低延遲多區域中繼節點

| $12/月 | $12 | 2 GB | 2 | **3 TB** | $0.09 |

#### 方案 B：AWS EC2
| 規格 | 月費（美東） | RAM | 含流量 | 超額流量 |
|------|-------------|-----|--------|---------|
| t3.micro | ~$7.59 | 1 GB | 100 GB | **$0.09/GB** |

> Lightsail $7/月 包含 **2TB 流量**，同等流量在 EC2 需額外付 **$180**（2TB × $0.09）。
> 對於代理/隧道這種流量密集型應用，**Lightsail 成本只有 EC2 的 1/25**。

## 五、網路使用量的計算方式

### 流量計量架構

```
App Client ──── Diode Node (Agent) ──── Backend
                    │
                    ├── 每 30 秒回報：
                    │   {
                    │     "bytes_in": 1234567,
                    │     "bytes_out": 7654321,
                    │     "active_connections": 15
                    │   }
                    │
                    └── Agent 使用 iptables/nftables 統計
                        或 diode_client 內建流量計數器
```

### 需要新增的計量功能

#### 1. Connection 增加流量欄位
```sql
ALTER TABLE connections ADD COLUMN bytes_in  BIGINT DEFAULT 0;
ALTER TABLE connections ADD COLUMN bytes_out BIGINT DEFAULT 0;
```

#### 2. App 增加月流量統計
```sql
ALTER TABLE applications ADD COLUMN bandwidth_limit  BIGINT DEFAULT 107374182400; -- 100GB
ALTER TABLE applications ADD COLUMN bandwidth_used   BIGINT DEFAULT 0;           -- 當月已用
ALTER TABLE applications ADD COLUMN bandwidth_reset_at TIMESTAMP WITH TIME ZONE;  -- 下次重置
```

#### 3. Agent Heartbeat 增加流量回報
```json
POST /api/agent/heartbeat
{
  "client_address": "203.0.113.5:41046",
  "status": "running",
  "connections": [
    { "session_id": "sess-001", "bytes_in": 52428800, "bytes_out": 104857600 },
    { "session_id": "sess-002", "bytes_in": 10485760, "bytes_out": 20971520 }
  ]
}
```

#### 4. 流量超限處理
- 接近 80%：API 回應加 warning header
- 達到 100%：新連線回傳 `429 bandwidth_limit_reached`
- 現有連線不中斷，但通知 App
- 超額部分按超額費率計算

### 使用量上限的概念

```
┌─────────────────────────────────────────┐
│ App: "MyGame"                           │
│ Plan: Pro ($99/月)                      │
│                                         │
│ 同時連線: ████████░░ 80/100 (80%)       │
│ 月流量:   ██████░░░░ 600GB/1TB (60%)    │
│ API 調用: ██░░░░░░░░ 20K/100K (20%)     │
│                                         │
│ 超過任一上限 → 回傳限制訊息或按超額計費  │
└─────────────────────────────────────────┘
```

## 七、競爭分析

| | Diode Cloud | Cloudflare Tunnel | Tailscale | ngrok |
|---|---|---|---|---|
| **定價** | $0-399/月 | $0-$7/用戶 | $0-$18/用戶 | $0-$39/月 |
| **加密** | E2E（後台不解密） | 終止 TLS（可看內容） | E2E (WireGuard) | 終止 TLS |
| **API 整合** | 原生 REST API | CLI 為主 | CLI + API | API |
| **自訂節點** | 可自訂區域部署 | Cloudflare 網路 | 使用者自己的機器 | ngrok 網路 |
| **流量費** | 包含在方案內 | 無限（免費版） | 無 | 有限 |
| **差異化** | 完全去中心化 + API 原生 | 速度快但不加密 | P2P 但非代理 | 開發工具為主 |

### 我們的差異化優勢
1. **真正的 E2E 加密** — Cloudflare/ngrok 都會終止 TLS
2. **API-first** — 專為 App 整合設計，不需要用戶裝 CLI
3. **靈活區域** — 可在任何地方部署節點，不被綁定在特定網路
4. **透明定價** — 按連線+流量，不是按用戶數
