## 1. 產品是什麼？

### 一句話

> 我們提供「**加密網路通道即服務**」，讓 App 開發者透過 API 一鍵接入全球加密代理網路，按連線人數和流量計費。

### 生活化比喻

把我們想成「**國際快遞的高速公路系統**」：

- 我們在全球建了**收費站（節點）**
- 客戶來**租用車道（連線數）**
- 用戶走我們的高速公路，按**車道數 + 里程數（流量）**收費
- 高速公路有**加密護送**，連我們自己都看不到貨物內容

### 核心價值

| 特點 | 說明 | 客戶好處 |
|------|------|---------|
| 端對端加密 | secp256k1 加密，連我們的伺服器都無法解密 | 真正的隱私保護 |
| API 原生 | 用 API Key 呼叫就能取得節點、建立連線 | 整合快，不需用戶裝軟體 |
| 全球多區域 | 亞洲、美洲、歐洲節點隨時擴展 | 就近連線，低延遲 |
| 即時管理後台 | Web 介面監控節點、連線、用量 | 一目了然的營運狀態 |
| 彈性計費 | 同時連線數 + 流量，用多少付多少 | 無浪費，可預測成本 |

## 3. 怎麼運作？（簡化版）

```
① 客戶在後台註冊，選方案 → 取得 API 金鑰

② 客戶的 App 用 API 金鑰呼叫我們 → 取得最近的可用節點

③ 用戶透過節點建立加密連線 → 開始使用

④ 我們即時追蹤：用了幾個連線、跑了多少流量

⑤ 月底依用量結算
```

### 多租戶架構

```
租戶（客戶公司）
  └── 應用程式 A（API 金鑰 A）
  │     ├── 同時連線上限：100
  │     ├── 月流量上限：1 TB
  │     └── 可用區域：新加坡、東京
  │
  └── 應用程式 B（API 金鑰 B）
        ├── 同時連線上限：20
        ├── 月流量上限：100 GB
        └── 可用區域：新加坡
```

一個客戶可以有多個應用程式，每個應用程式有獨立的額度和金鑰，互不影響。

## 6. 毛利分析

### 每方案毛利

| 客戶方案 | 月費 | 我們的成本 | **毛利** | **毛利率** |
|----------|------|-----------|---------|-----------|
| Starter（20 人 / 80 GB） | $29 | ~$2.7 | **$26.3** | **91%** |
| Pro（100 人 / 800 GB） | $99 | ~$10.5 | **$88.5** | **89%** |
| Business（500 人 / 4 TB） | $399 | ~$49.5 | **$349.5** | **88%** |

> 成本拆解：連線成本（連線數/200 × $7）+ 流量成本 + 後台分攤（~$2）

### 為什麼毛利這麼高？

1. **Lightsail 含大量免費流量** — $7/月包 2TB，邊際流量成本趨近於零
2. **一台節點服務多個客戶** — 200 個連線共享一台 $7 的機器
3. **軟體邊際成本為零** — 後台系統開發一次，服務所有客戶
4. **API 自助服務** — 不需要客服人力（Enterprise 除外）

### 損益平衡

| 場景 | 客戶組合 | 月收入 | 月成本 | 盈虧 |
|------|---------|--------|--------|------|
| 最低門檻 | 2 個 Starter | $58 | $54 | **+$4** |
| 穩定運作 | 5 Starter + 3 Pro | $442 | ~$200 | **+$242** |
| 規模化 | 10 Starter + 10 Pro + 2 Business | $2,078 | ~$700 | **+$1,378** |

> **僅需 2 個 Starter 客戶即可損益平衡。**

## 7. 競爭優勢

| | Diode Cloud | Cloudflare Tunnel | Tailscale | ngrok |
|---|---|---|---|---|
| **定價** | $0-399/月 | $7/用戶/月 | $18/用戶/月 | $39/月 |
| **計費方式** | 連線+流量 | 按用戶數 | 按用戶數 | 按功能 |
| **加密** | **E2E（不解密）** | 終止 TLS（看得到） | E2E（WireGuard） | 終止 TLS |
| **API 整合** | 原生 REST API | CLI 為主 | CLI + API | API |
| **自訂節點** | 可部署任何區域 | Cloudflare 網路 | 用戶設備 | ngrok 網路 |

### 關鍵差異

1. **真正 E2E 加密** — Cloudflare/ngrok 會解密流量，我們不會
2. **API-first** — 專為 App 整合設計，客戶的用戶不需裝任何軟體
3. **靈活區域** — 可在任何 AWS 區域（含香港）部署節點
4. **透明定價** — 按連線+流量，不是按用戶數（大量用戶時更划算）

### 定價競爭力

以 20 個同時在線用戶為例：

| 方案 | 我們 | Cloudflare | Tailscale |
|------|------|-----------|-----------|
| 月費 | **$29** | $140（$7×20） | $360（$18×20） |
| 每人成本 | **$1.45** | $7 | $18 |

> 用戶數越多，我們的價格優勢越明顯。

## 8. 客戶需求評估指南

業務接觸潛在客戶時，用以下問題快速評估適合的方案。

### 8.1 關鍵問題

| # | 問題 | 用途 |
|---|------|------|
| 1 | 你們的 App 大約有多少用戶會**同時在線**？ | 決定連線數上限 |
| 2 | 每個用戶每次使用多久？傳輸什麼資料？ | 估算月流量 |
| 3 | 用戶主要在哪些地區？ | 決定需要哪些區域的節點 |
| 4 | 有流量尖峰嗎？尖峰約平時幾倍？ | 是否需要更高連線上限 |
| 5 | 有資安合規需求嗎？ | 是否需要 Enterprise |

### 8.2 快速估算

#### Step 1：估算同時在線

```
同時在線 ≈ DAU × 同時在線比例

常見比例：
  · 一般 App：5-10%
  · 即時通訊：15-25%
  · 遊戲：10-20%
  · IoT 設備：通常 100%（設備一直開著）
```

| DAU | 同時比例 | 同時在線 | 建議方案 |
|-----|---------|---------|---------|
| 50 | 10% | 5 | Starter（$29） |
| 200 | 10% | 20 | Starter（$29） |
| 500 | 15% | 75 | Pro（$99） |
| 2,000 | 10% | 200 | Business（$399） |
| 10,000 | 10% | 1,000 | Enterprise |

#### Step 2：估算月流量

```
月流量 ≈ 同時在線 × 每人每小時流量 × 每日時數 × 30 天

常見每人每小時流量：
  · IoT 感測器：0.001 GB/hr
  · 文字/指令：0.01 GB/hr
  · 一般網頁：0.1 GB/hr
  · 檔案傳輸：0.5-2 GB/hr
  · 影音串流：1-3 GB/hr
```

| 使用情境 | 同時在線 | 每人/hr | 每日時數 | 月流量 | 建議方案 |
|----------|---------|---------|---------|--------|---------|
| IoT 監控 | 50 台 | 0.001 GB | 24 hr | 36 GB | Starter |
| 企業 VPN | 20 人 | 0.1 GB | 8 hr | 480 GB | Pro |
| App 代理 | 100 人 | 0.05 GB | 2 hr | 300 GB | Pro |
| 直播推流 | 10 人 | 2 GB | 4 hr | 2,400 GB | Business |

#### Step 3：取兩者中較高的方案

```
最終方案 = max（同時在線建議, 流量建議）

例如：同時在線 20 人 → Starter
     月流量 480 GB → Pro（超過 Starter 的 100GB）
     → 最終建議：Pro（$99/月）
```
